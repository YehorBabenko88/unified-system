# Unified release/acceptance preparation package

This exact package is NOT an approved/installable release. Runtime/physical acceptance, production deployment and Tailscale retirement remain BLOCKED. Only independently controlled disposable acceptance is authorized.

release-manifest.json pins all six source HEAD/tree/PRs. integration-baseline.json separates the audit baseline from component development bases. ownership-registry.json lists exclusive scopes and pending acknowledgements. contract-status.json distinguishes preserved/proposed/versioned artifacts and unapproved or drifted bytes. No schema/design ACK is promoted to runtime safety.

node-inventory.json contains six owner-supplied LAN candidates and bounded observation scope. egress-observation.json records six equal observed IPv4 exits for one HTTPS endpoint, not proof of all Bybit routes or unmanaged IP quota. Actual public IP and host keys remain in owner-local evidence.

ci-evidence-index.json references independently collected original logs/artifacts. Metadata and narrow component tests are not a complete matrix or integrated PASS. rollback-plan.md and physical-acceptance-plan.* are plans only. All physical fault injection needs separate explicit owner permission.

Use the immutable Git commit URL supplied by Integration Owner and package-index.json hashes; do not consume a mutable branch or a local WIP as approval.
