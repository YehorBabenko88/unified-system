# Collector synthetic integration candidate

This is source implementation, not C0–C8 acceptance or service admission.
The existing full-runtime profile remains separate. The collector capsule kind
is explicitly refused by the old service plan and resource revalidation path.

The versioned profile and entry compose actual Grid Worker receive, raw recorder,
A4 raw adapter, ObjectStore and Journal, persistent context and bounded logger.
`integration/collector/v1/source-inputs.json` binds selected application bytes and
immutable component inputs; external qualification must verify primary source,
runtime bytes and actual loaded origins. The manifest is not an execution grant.

Only finite synthetic offline inputs are supported. No provider REST/WebSocket,
trading, training, Math, authority mutation, public submit, service creation or
ACL changes are admitted. PostgreSQL metadata adapter source is present; actual
disposable PostgreSQL qualification is not yet complete.

## Operational CI admission

Ordinary push and PR events fail the stopped-service admission before HTTP or
native effects; its native job is skipped. Manual execution additionally requires
an exact source-bound owner record and real run-specific protected-environment
review. No approved record or dispatch is supplied here. A skipped native job is
not a qualification PASS. Repository branch-protection settings are not attested.

Six historical workflows on earlier component branches had already completed
native service/ACL fixture steps in twelve GitHub-hosted Windows jobs before this
guard was added. Their evidence is retained independently. They are not Collector
C3 acceptance and made no LS5 installation. Do not rerun those older unsafe
source snapshots. This candidate does not disable workflows or alter settings.
