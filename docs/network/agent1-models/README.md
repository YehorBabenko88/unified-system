# Agent 1 network safety models — MODEL_ONLY

This separate test-only branch prepares independent negative tests while the direct-human full LAN implementation approval remains pending. It implements no application transport, mTLS, actual Network Budget Manager, provider enforcement, Consul authority, native persistence or physical acceptance. All model support lives under tests/network_model; nothing in unified_system is changed/imported. No sockets, provider calls, office traffic or network configuration actions occur. Only test-owned temporary checkpoint files are written by persistence tests.

Run `python -m unittest discover -s tests/network_model -v` and `python tests/network_model/run_evidence.py --source <tested-commit>` with Python3.11+. Standard library only. Use the explicit model test directory; existing top-level unittest discovery may not recurse into a non-package directory. Own CI invokes that exact command on Windows/Ubuntu3.11/3.13. Local execution is not hosted CI.

The simulator has six fixed synthetic node labels and ten synthetic instrument IDs. Integer virtual milliseconds drive fixed per-node and aggregate token buckets plus class caps: control200/live500/bulk300 bytes/s per node,1000bytes/s/node,6000bytes/s aggregate, initial bursts equal those rates. These are toy numbers, not production policy. Explicit bounded FIFO queues per class use strict control/live/bulk selection within independent class caps; caps preserve progress without allowing a high-priority class to take bulk capacity. No policy borrowing, work placement, receive-credit protocol or transport authentication is modeled. Interval tests compare attempted bytes against independent rate*duration+burst envelopes. Latency/jitter and deterministic loss affect delivery, never undo the attempted-byte debit; no automatic resend occurs.

LS5 failure disables its scheduler visits, not other nodes or networking. Static surviving allocations never expand. Restarted LS5 starts with empty byte buckets at10% rate and advances100ms recovery stages up to its unchanged ceiling, accruing tokens at the old rate first. Queued packets remain producer-owned/model-visible; attempts and lost/delivered/inflight counts are separate. Enqueue refusal is explicit backpressure, never a reported successful delivery. Test workloads are finite and small; simulator trace lists are not an implementation of bounded runtime telemetry retention.

QuotaLedger is a shared synthetic NAT thought experiment, not Bybit policy or distributed storage. Fixture nat1 is not an observed public IP. Synthetic quorum/gate flags are explicit model inputs, not production identity/authority adapters. Reserve/consume/UNKNOWN/cancel, maximum cooldown, sticky freeze, diagnostic failover and checkpoint restore illustrate conservative invariants. Unknown or possibly late charged attempts retain debt across virtual windows; no counterpart proves real sender containment. UNKNOWN blocks scope reuse, consumed receipt replay returns only historical status, and closed gates block unconsumed cancellation/refund. It supplies no successful provider response/civil-time window qualification or adaptive quota activation path.

Checkpoint JSON/checksum tests detect accidental corruption and malformed shape in disposable files. A checksum is not authentication, protected admission, atomic durability, fsync proof or crash-consistent Consul state. Missing/corrupt state and backward virtual clock fail closed. Model flags are never fed to production factories. Full TLS negative tests, actual stream backpressure, node-wide multi-process IPC, persistent real budgets, quorum/fencing, certificate trust, Windows native ACLs, actual Tailscale independence and office acceptance are NOT_RUN by this branch.

`run_evidence.py` prints deterministic MODEL_ONLY counts and synthetic latency quantiles. Its source_commit label is supplied by the caller/CI; it is evidence binding metadata, not source admission. Zero provider/socket/reset counters describe the model boundary, not measured office behavior. No model result can open the frozen Egress activation/containment gates or replace direct human design approval.
