## Exact implemented interfaces and limits

`PeerRegistry.from_document` accepts only schema unified.lan-peer-registry.v1, cluster_id lowercaseUUIDv4, generation integer1..2^63-1 and exactly six node rows. Each row has node_id (LS5/PC1/PC2/PC3/PC4/LS7), unique enrollment_id UUIDv4,1..2 unique lowercase leaf SHA256 fingerprints, roles from control/ingestion/storage,1..4 literal-IP endpoints {address,port,priority,transport=lan|tailscale}, and enabled boolean. Document<=64KiB; immutable peers/endpoints; LAN endpoints sort before explicit tailnet alternatives. No network auto-enrollment or implied IP trust. Auth requires chain, TLS purpose EKU, validity, ALPN unified-lan-v1, exactly one node SAN URI urn:unified:<clusterUUID>:<node_id> and enrolled DER fingerprint. Registry update is monotonic; changed identity/role/endpoint closes affected channels immediately (within proposed drain bound).

`tls_context(ca,cert,key,server=...)` uses required peer certificates, TLS>=1.2, normal dedicated CA verification and SSL purpose checking. Isolated tests generate actual EC certificate material in temporary directories using OpenSSL; no keys/certificates or OS trust changes in Git. Required tooling absence fails tests rather than skipping security cases.

`LanTransport.isolated` requires a registry, two verified SSL contexts and same-node `NodeBudget`. It binds/dials loopback literals ONLY, including when a registry contains an office address. `runtime` raises NATIVE_RUNTIME_ADMISSION_REQUIRED. Listen queue12; max5 peer connections,2 concurrent outgoing connection attempts and one attempt/peer; incoming pairs are admitted serially with5s default bound. Every peer has separate control/data TLS sockets tied to one authenticated peer/session nonce; no ambient DNS/SSH/Tailscale calls. Certificate/pin failures are sticky until registry digest changes. Reconnect has exponential full jitter0.25..30s, cancellation/deadline and stable-session reset60s. No auto resend of uncertain application data.

`Connection.send(payload,class,stream_id,deadline,cancel)` returns a socket-write message ID, NOT an application/durable acknowledgement. Classes map control->control role,live->ingestion,bulk->storage. Control<=4096 payload bytes, data<=65536;16streams;64queued outbound/inbound frames;1MiB outbound payload/peer;8MiB shared node reservation ceiling. Stream credit starts0, receiver allocates a64KiB window from node memory before granting cumulative bytes, replenishes only on receive consumption, and rejects wrong-stream/excess grants. Queue/frame caps fail closed on overload. Small-message frame count exhaustion may disconnect rather than silently drop or claim reliable durable delivery. Two independent writer workers preserve control progress during data-budget/socket waits; reader prioritizes queued control/live/bulk, preserving class order. Infra credit/open/PING/PONG also consume bounded control budget. Heartbeat10s, idle reader bound30s, whole frame body5s. All threads have close signalling and owned sockets only; no process/system networking cleanup.

Framing is uint16 header length +uint32 payload length, strict bounded JSON header {kind,stream,traffic_class,message_id,value}. Unknown/duplicate fields, booleans for counters, invalid stream or role, oversize and uncredited data reject before dispatch. Data-credit and socket/TLS byte overhead are not equivalent; byte accounting charges plaintext frame prefix/header/payload, not encrypted TCP/TLS/link overhead. Receive admission conservatively reserves declared bounded frame bytes before reading payload; partial/failed reads may overcharge rather than refund. Peer schema/nonce is not execution authority.

`BandwidthPolicy` fixes all six node rate/burst ceilings whose sums fit cluster rate/burst, with positive class percentages summing100. `NodeBudget.isolated` uses one per-node SQLite store shared by all local participants, per-direction node/class/peer buckets and atomic debit/counters. Buckets start empty, restart does not create a burst, different boot clock IDs rebase empty, clock rollback is sticky blocked. Policy/node mismatch, foreign/incomplete/link/reparse store fail closed. Static allocation never borrows after LS5 loss. This proves shared-store atomicity under actual process contention, NOT that every office process is forced to use that store; native protected path/identity/IPC admission remains absent. No SQLite cluster election/authority exists.

`EgressProjection.isolated` persists verifier-admitted event ID/digest, immutable attempt/scope/cost/policy, conservative usage, maximum cooldown and sticky UNKNOWN freeze. Test verifier callback is explicitly a test seam, not a native authority assertion. Duplicate exact event is inert, conflict/cost/scope/policy substitution rejects; OBSERVED cannot clear old freeze/debt. CANCELLED/refund is rejected in closed profile. It never issues distributed grants: acquire/prepare_dispatch always SAFETY_GATE_CLOSED; runtime factory AUTHORITY_ADAPTER_NOT_ADMITTED.1024attempts/8scopes/store16MiB bounds; missing/corrupt storage is not fresh zero allowance.
