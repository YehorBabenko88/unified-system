# Close the unbudgeted provider probe

The fixed read-only observer previously reached Bybit DNS/TCP/GET without the
shared provider policy/reservation/usage adapter. Read-only requests still consume
provider and office network capacity. A8 independently reproduced this source gap
at integration source 0346018; it is not proof of actual unauthorized traffic.

Until a separately qualified adapter exists, Probe-Public accepts only the fixed
general Microsoft connectivity operation. A true provider flag, a different host
or a different URL returns all four checks NOT_RUN with
BYBIT_BUDGET_ADAPTER_NOT_ADMITTED before any network primitive. A false flag cannot
admit a provider target. No environment override, fallback, retry, budget or
operational authority is added. The existing operational v1 guard is unchanged
and rejects this blocked observation. This is not inert-bootstrap evidence.

The new test extracts the actual PowerShell function AST and replaces exactly
three DNS/socket/HTTP seams with a counter and exception. Six denied vectors
reach zero seams; the unchanged general branch reaches the DNS sentinel. No
actual DNS/TCP/HTTP or office-node command is executed. An additional dominance
check and the existing v1 guard verify the closed boundary. Original RED and
GREEN logs/commands/hashes are preserved on the integration evidence branch.

Local Windows result: 56 tests, zero failures/errors/skips. The broader 812-test
result belongs to its original source and is not transferred to this patch.
Hosted CI, native runtime, shared network budgets, destination-specific Bybit
egress, and physical acceptance remain unqualified. No deployment is authorized.
