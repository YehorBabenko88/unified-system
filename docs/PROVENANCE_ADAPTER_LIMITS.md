# Provenance v1.1 adapter limits
The standalone offline adapter checks outer shape, a canonical receipt digest and a separately supplied exact receipt pin. It **does not** independently reimplement Strattester's complete input-snapshot validation, nor verify runtime identity, trusted policy origin, producer epoch, source timestamps or market authenticity. Even a matched owner pin yields UNAVAILABLE until the source-owned oracle is independently exercised and accepted. Grid statuses PARTIAL/STALE/GAP/UNAVAILABLE remain non-trading, and an untrusted AVAILABLE is rejected. No network I/O or real database access.
