## Existing behavior that must survive

The disposable stand is local test-call custody, not authentication or kernel authority. Its owned marker, exclusive OS file lock, bounded existing Journal, mutex and decision lock remain. STARTED is durable before any analytic invocation. A STARTED-only intent after crash/unknown is never executed again. Exact request/idempotency retries return the immutable finished envelope; either identity collision refuses. Cancellation before execution prevents invocation; cancellation after computation discards artifact before commit. Revocation/expiry and final FINISHED commit share decision-lock ordering. Lost/uncertain calculation never becomes a second execution. Preserve maxima:16KiB input/envelope,8KiB analytic artifact,3 fixed rows,1 execution,64 journal events,2MiB journal file,32 local contexts,64 cancellation IDs,60second local context cap. Cooperative in-process cancellation is not CPU/RSS containment or native process qualification.

## Exact source custody before application import

Reuse the existing Root integration.source_guard.SourceFence implementation, as lab_runtime.verify_sources already does; no second Git/source verifier. Trusted commissioning supplies exact admitted source roots plus pinned absolute Git executable/hash. Require matching source commits/trees, ordinary standalone metadata, approved origin, no filters/includes/replace/alternate/promisor metadata, clean index/untracked code and ALL runtime comparisons RAW_IDENTICAL. Before importing application code, reject any already-loaded Terminan or Math module from a foreign/unverified origin; do not silently purge/unload foreign modules. Use only verified source roots plus trusted interpreter/stdlib dependency paths for app resolution. Verify module origins and recheck source/runtime trees after invocation before accepting artifact. The existing pinned Root infrastructure must itself already be commissioned; a SourceFence proves source consistency, not publisher trust or actual execution authority.

No arbitrary analytic callback, callback grant, sys.path public override, legacy dynamic Stratt wrapper or source bytes exec fallback. Missing custody, origin mismatch, changed source, missing canonical Math or target refusal yields bounded failed/unknown outcome while preserving durable STARTED/no-reexecution semantics. Exact source pin constants and fixture descriptor SHA are private fixed-profile metadata, not credentials or public activation knobs.
