# Disposable loopback transport smoke
Tests run the opt-in Supervisor WSGI callable inside a disposable in-process HTTP server bound only to 127.0.0.1 on an OS-assigned port. The test checks GET capabilities, POST rejection, clean shutdown and no trading authority on Windows/Linux. This is **not** an installed service, authenticated remote endpoint, production-grade transport or proof of Windows physical containment. No real source API is connected. A production listener must separately implement identity binding, authentication, resource bounds, shutdown, replay protection and independently authorized deployment.
