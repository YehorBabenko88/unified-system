# Identity Consul guards v1 — implementation seam, not native admission

ROOT owns `unified_system/security_identity_records.py`. The exact executable `IdentityBinding` and strict decoder define fields/encoding. Native provider resolves cluster/principal/session/enrollment/policy/node UUIDv4 IDs from a qualified local Windows identity and listener; never from HTTP, JSON claims, a boolean, or a caller-selected KV path. Native provider compares the actual kernel SID, local logon LUID, node enrollment and current RBAC to the authoritative records. Record parsing alone supplies no authentication.

Keys are fixed under `unified/<cluster UUID>/security/v1/`: principals/<principal UUID>, sessions/<session UUID>, enrollments/<enrollment UUID>, policies/<policy UUID>. All values are canonical sorted ASCII JSON, <=16384 bytes, no numeric JSON, duplicates, unknown fields or versions. Revisions are positive u63 decimal strings. Policies contain sorted unique supported Mux operations, with no real-trading capability. A record state other than ACTIVE rejects. Returned records are deeply immutable.

A2 adapter must consistently read all four records from the EXISTING authority; independently capture actual positive ModifyIndices and verify the records with the expected native-resolved binding. SAME Consul transaction must check those exact indices AND the existing leader/session/generation checks AND slot/command/request UUID/receipt CAS. Any record change/deletion, missing quorum, lock loss or ambiguous transaction outcome denies/reconciles; never substitute local success, a double Python check or timestamps. Do not expose arbitrary KV path/index/txn-op input at the public boundary.

Records are not provisioned by this module. A commissioning/native bridge must be independently implemented and qualified. Tests use explicit untrusted fixture records and do not create trusted sessions. Native expiry, revocation, Windows token lifetime and CSRF/session admission are independent gates; no clock times are inferred from Consul indices. No expiry grace period or retry-after-UNKNOWN permission is implied.

Publication/assignment guards remain a different record family under A2/A4/A5 agreement; this security namespace creates no second consensus, authority or publication backend. Status: CODE implementation available; atomic adapter ACK/integration and Windows native runtime admission PENDING.
