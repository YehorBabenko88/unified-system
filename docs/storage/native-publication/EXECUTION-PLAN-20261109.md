## Executable slices and dependencies

1. Actual retained bytes: original producer/target requests, input closure,
   computed artifact, descriptor and truthful source/algorithm/units/provenance.
   Verify exact bytes/hash/length/schema and complete acyclic dependencies before
   producing a candidate. Retain existing local copy API semantics separately.
2. Actual destination copy/readback and verifier: distinct admitted store/node/
   volume/incarnation/domain, current eligibility, protection/holds and issued
   reservations. No domain label supplied in JSON proves independence. Actual
   observations are stored only through the same A2 authority/issuer contract.
3. Native publisher adapter: fixed A2 source/instance API, not an injected callback
   or raw caller operation plan. A2 constructs the complete transaction checking
   assignment supersession/attempt/cancel, current closure/replicas/holds/budgets,
   dataset CAS/original idempotency/access and atomically writes root/revision/
   receipt/protection/accounting. Exact schemas and key-to-CAS mapping co-ACK
   A2/A4/A5 before positive wiring. Fully encode/measure every actual plan.
4. Reconciliation/recovery: consistent same-original lookup under current rights;
   immutable exact native KV Value receipt bytes plus external actual ModifyIndex.
   Crash before send, uncertain send, commit-before-response and projection crash
   are distinct. Never reconstruct an opaque proof from JSON or retry with a new
   key. Physical corruption/loss revokes eligibility and blocks further unsafe
   publication; all-lost produces explicit unavailable/unrecoverable ranges.
5. Existing A7 ResultStore projection/read: only an actual consistently resolved
   receipt, exact artifact/root/revision/identity and current READ scope admit
   durable projection/disclosure. Shared exact API and error/codecs co-ACK owners.
   A6 receives actual scientific bytes/descriptor, never metadata-only chart data.
