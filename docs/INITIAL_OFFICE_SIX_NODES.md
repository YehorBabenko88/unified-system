# Initial office fleet — six PC commissioning checklist (no actions performed)
Initial target is six Windows office PCs, not six assumed healthy workers. Before any change capture owner-authorized non-secret inventory: machine identities, OS/build, effective user/admin roles, service identity, CPU/RAM/disk free capacity, existing Postgres/SQLite/ports, installed software/version/digest, storage paths, available backups, DNS, LAN/router/switch/power failure domains, SSH/Tailscale status and applicable endpoint-management policy. Record source and timestamp; unknown remains UNKNOWN.

A topology view shows observed nodes, authenticated direct links (when actually tested), network overlay edges separately from LAN wiring, assigned tasks and their lease state, alert history, database sizes, recovery point, capacity/headroom and which controls are locked awaiting authorization. Do not fabricate physical links from successful Tailscale reachability.

Use stage gates DISCOVER -> OWNER_APPROVE -> READ_ONLY_G0 -> SIGNED_PLAN -> AUTHORIZED_APPLY -> VERIFY -> ACTIVE. Only verified and approved PCs may join scheduling. A user logging out must not disrupt an administrator-managed Windows service; however service operation must follow Windows account privileges, organizational policy and vendor terms. Ordinary users should not receive control/admin permissions. Never covertly hide Tailscale or override an administrator's right to disconnect.

Never create/alter service, firewall, database, SSH key, ACL, Tailscale account or system package automatically until a separate operation and owner authorization qualifies the exact host and mutation. Preserve existing independent modules and data ownership. A removed PC enters DRAINING then RETIRED with an explicit revocation receipt, not a silent erase.
