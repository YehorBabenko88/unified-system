# Private read-only source handoff

ProcessDriver issues UNIFIED_MARKET_DATA_READ_CAPABILITY only to the Terminan child after exactly one current owned market_data process passes functional health. The bounded transient environment value binds IPv4 loopback port, per-start bearer, source commit recorded at the actual Data start, release ID and operation epoch. It is never program.env, public config, journal or snapshot. Inherited copies are stripped for every child; public overrides (any casing) are refused at construction and start verification. Only the nonsecret dependency epoch enters the Terminan private process record. Reusing a Terminan operation against a new Data epoch refuses. The existing canonical DAG stops/restarts Terminan on Data fault.

Owned PostgreSQL credentials use the existing protected sealed pgpass.conf plus receipt digest/current process proof. PostgresOwnership.runtime_environment returns PGPASSWORD only for market_data. Bootstrap never injects it into Math/Terminan; driver strips inherited/callback database credentials from other children and rejects public PGPASSWORD/PGPASSFILE. No additional credential file/schema is introduced. Shared exact pgpass parsing refuses duplicate matching records.

Terminan consumes/pops the environment value before binding its listener, validates source/release against live source admission and constructs a private route-scoped client. Only four existing internal read-only GET routes are allowed. Current admission is checked before/after transport. Old Data bearer after restart is rejected by the existing canonical Data guard; failure remains UNAVAILABLE/empty, with no SQL fallback. Offline standalone Terminan does not require this capability. Paper/state journals are untouched.

Evidence: 89 scoped Unified pure/fake tests and22 Terminan pure client/data/startup cases PASS on CPython3.11 and3.12. Native subprocess/os.system audit-denied; client/actual-guard cross-owner tests also deny socket construction. Exact driver issuer -> Terminan client -> actual Data managed-request guard accepts current source and refuses rotated/revoked source, using inert transport only. No actual HTTP, service, SQL/native process, installer or security-setting action. Existing forbidden native tests stay enabled/unexecuted. Raw service registration must repin changed entry/bootstrap bytes. Full native acceptance remains NO_GO.

Private injection defensively copies the environment-provider mapping before mutation; a cached/public dictionary supplied by a provider cannot retain the capability, instance token or cache paths. Regression reproduced RED before the copy, then GREEN.
