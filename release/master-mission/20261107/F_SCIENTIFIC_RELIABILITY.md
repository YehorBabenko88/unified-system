# F — Scientific reliability

Report expectancy after explicit costs and uncertainty, sample population, units, strategy/version and data provenance. Touch is not guaranteed fill: disclose queue, latency, partial-fill, slippage and funding assumptions. Local ledger atomicity is not distributed exactly-once. PaperLedger pnl is already net; direct conversion into Math gross-pnl helper would double subtract fees/slippage. That is an incompatible DTO, not proof that an existing integrated route is broken.

Strattester already has purge/embargo and fresh-fold safeguards; opt-in sequential OOS reuse is not independent OOS. Math train/validation/test within a window does not establish a global cross-experiment lockbox. MetaAnalyse declared availability is not observed point-in-time availability. Bootstrap intervals are exploratory, not calibrated probability or profit guarantees.

Grid267 bounded overflow correction passed 10 new and 21 combined local tests. Independent oracle comparison permits one-ULP differences; do not claim universal correctly rounded means. This is not full scientific calibration.

Promotion DISCOVERED → BACKTESTED → OOS_PASSED → LIVE_VALIDATED → PAPER_ACTIVE requires explicit evidence at each gate. High historical return alone never promotes a strategy. No live/provider acceptance, native PASS or physical acceptance is inferred from synthetic data.
