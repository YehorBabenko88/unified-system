## Accepted proposed semantics

Sole existing Consul authority; no-majority denial; both actual leader-session/
index and lease-session binding/index; exact generation/assignment/grant/worker/
reservation/closure/debit predicates in one atomic publication; old authority
rejected after committed invalidation even without a successor; renewal changes
checked grant revision; consistent original UNKNOWN receipt reconciliation with
no successor rekey/double debit. No second clock/authority or precheck+SQL commit.

Publication-before-invalidation remains valid committed history; invalidation-
before-publication rejects all effects. These semantics support ingestion lineage,
durable cursor adoption, dedup and gap evidence without inventing commit UTC.
Unknown or partially renewed session/grant does not produce a fresh token.
