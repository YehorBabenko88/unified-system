# Bounded official artifact custody

The accepted source-only aggregate remains a pure consistency checker and always returns coverage HELD. artifact_custody.mjs is a separate read-only network/archive boundary: it obtains current Math run/attempt jobs, PR and artifact metadata from fixed api.github.com endpoints, plans exactly four expected cell artifactIDs, then requests only their fixed /actions/artifacts/<id>/zip endpoints. No metadata-provided archive URL is used.

The API request uses redirect:manual and the bearer only on api.github.com. Only a302 to HTTPS productionresultssa[0-9]{1,3}.blob.core.windows.net is permitted, with no userinfo, nondefault port or fragment. This restricted account family is based on the observed official productionresultssa4 endpoint; new host families fail closed pending source review. The blob request has no Authorization, credentials:omit, no-referrer and redirect:error. No URL/query/header/token/exception text is logged, persisted or returned. The same readonly metadata is fetched again after download; changed run/attempt/job/check-run/artifactID/digest/size makes the result HELD. Requests/streams have fixed time/byte bounds and no retry.

Each archive is at most1MiB compressed; its bytes must match BOTH actual GitHub artifact size and sha256: ZIP digest. JSON content digest is never substituted. The in-memory parser requires one exact allowlisted cell basename, classic ZIP32 local/central/EOCD offsets and sizes, regular-file mode, CRC, no extra/comment/disk/hidden member, no encryption or ZIP64. It supports STORE or raw deflate, optional UTF8 flag and the observed16-byte signed data descriptor. inflateRawSync uses maxOutputLength equal to the declared member size (at most64KiB) and verifies consumed compressed bytes; concatenated/trailing deflate streams and expansion past the limit refuse. Nothing is extracted to disk. The raw buffer is detached before checksum/parsing.

The literal bytes are retained in the inert test and bound by provenance/official-artifact-wire.json; redirect proof stores only host/status, never signed query. A generic explicit-basename decoder proves this fixture, while readCellArtifact refuses it because it is not roles-<cell>.json.

After actual ZIP custody and unchanged post-metadata, all four canonical cell receipts must pass the existing per-cell/source/role checks. A successful collectRootRoleCoverage result has scope ROOT_FOUR_DOWNLOADED_UNIT_ARTIFACTS, coverage ROOT_FOUR_UNIT_CELLS_ONLY, authority NONE, source_authentication NOT_EVALUATED, native_acceptance NOT_QUALIFIED and production NO_GO. It does not authenticate callers or authorize C3/trading. Inert fake-HTTP positives are calibration only; no real four-cell hosted coverage is claimed locally. Math still must run its actual original six-axis validator and require both results; no sixPassed boolean/callback exists.

Root kit now comprises eight source/data entries plus the workflow (nine hash-bound files); RAlpha role-library31inputs and original34roles/fourcells stay unchanged. ## Transport fragment resource repair

The archive body reader now preallocates one bounded buffer, copies bytes directly and retains no array or copy per received fragment. Empty chunks refuse immediately; at most4096nonempty chunks are accepted per archive. This is a transport representation/work budget, not a provider/domain maximum. The independent10second body deadline and per-chunk monotonic time checks bound silence/slow progress, while early refusal asks the iterator to close without awaiting an untrusted close. The original HTTP timeout and compressed-byte/digest bounds remain unchanged.

Seven private-function inert cases preserve a valid two-fragment read, byte overflow and add zero/empty flood,4097th tiny-fragment, no-byte EOF, silent deadline/iterator close and delayed progress refusals, using a deterministic VM clock/timer with no real network/time wait. The original20,000empty-fragment witness is retained as RED; it now refuses after the first. This repair is only artifact_custody.mjs. RAlpha github_identity.mjs still has the separately assigned shared API fragment issue; role_source006418 is not silently relabeled as fixed.
